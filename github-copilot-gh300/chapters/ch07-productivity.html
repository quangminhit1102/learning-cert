Chương 07 Developer Productivity & Security

Năng suất và bảo mật

Dùng Copilot để sinh code, refactor, viết tài liệu, tạo test và phát hiện vấn đề bảo mật — cách khai thác AI để làm việc nhanh và an toàn hơn.

Bức tranh lớn

Copilot không chỉ gợi ý code: nó giúp hiểu code nhanh, giảm gián đoạn, hiện đại hóa code cũ, và nâng chất lượng qua test + rà soát bảo mật.

Tự kiểm tra5 điều bắt buộc nhớ

  1. Copilot hỗ trợ gì về code?

    Sinh code, refactor, viết tài liệu, sinh dữ liệu mẫu, hiện đại hóa code cũ.

  2. Copilot giúp học nhanh ra sao?

    Giải thích code lạ, giảm chuyển đổi ngữ cảnh khi tra tài liệu.

  3. Copilot hỗ trợ test thế nào?

    Sinh unit test và integration test, chỉ ra edge case, viết assertions.

  4. Về bảo mật, Copilot giúp gì?

    Gợi ý cải thiện bảo mật và tối ưu hiệu năng.

  5. Nguyên tắc khi dùng code Copilot sinh?

    Luôn review và chạy test trước khi dùng — kể cả code "cải thiện bảo mật".

Ghi chúSinh code, refactor và tài liệu

  • Code generation — sinh hàm/mô-đun từ mô tả hoặc từ test.
  • Refactoring — đổi tên, tách hàm, cải thiện cấu trúc mà giữ hành vi.
  • Documentation — sinh comment, docstring, giải thích code.
  • Sample data — tạo dữ liệu mẫu hợp lệ để test/phát triển.
  • Modernize legacy code — gợi ý cập nhật code cũ sang cú pháp/pattern mới.

Ghi chúTest và edge case

Copilot có thể sinh unit tests và integration tests cho code được chọn. Khi viết test, nó còn gợi ý edge cases (đầu vào rỗng, null, giá trị biên) và viết assertions tương ứng. Bạn vẫn phải đọc và chạy test để xác nhận.

Ghi chúBảo mật và hiệu năng

Copilot có thể gợi ý cải thiện bảo mật (validate input, tránh injection) và tối ưu hiệu năng (giảm vòng lặp, dùng cấu trúc dữ liệu hợp lý). Đây chỉ là gợi ý — không thay thế việc quét bảo mật và review.

Thực hànhÁp lên máy

  • 1. Sinh testChọn một hàm, dùng /tests, đọc và chạy test sinh ra.
  • 2. RefactorYêu cầu Copilot tách một hàm dài thành các hàm nhỏ, so sánh hành vi trước/sau.
  • 3. Edge caseHỏi Copilot "hàm này có edge case nào?", rồi viết test cho từng case.
  • 4. Bảo mậtĐưa đoạn code xử lý input, hỏi Copilot chỉ ra rủi ro bảo mật.
