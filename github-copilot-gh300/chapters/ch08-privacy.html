Chương 08 Privacy, Exclusions & Safeguards

Quyền riêng tư và biện pháp an toàn

Kiểm soát những gì Copilot được phép đọc, bộ lọc code trùng public, và cách xử lý khi gợi ý hoặc exclusion không như mong đợi.

Bức tranh lớn

Bạn quyết định Copilot thấy gì (content exclusions) và nhận gì (public code filter). Hai lớp này là hàng rào bảo vệ dữ liệu và bản quyền.

Tự kiểm tra5 điều bắt buộc nhớ

  1. Content exclusions có ở những cấp nào?

    Cấp repository (settings) và cấp organization (enterprise).

  2. File nào loại trừ nội dung trong repo?

    .copilotignore — hoạt động tương tự .gitignore.

  3. Public code filter để làm gì?

    Chặn gợi ý trùng khớp code công khai (suggestions matching public code).

  4. Ai sở hữu code bạn viết với Copilot?

    Bạn sở hữu code mình viết; nhưng cần chú ý code có thể trùng public và vấn đề license.

  5. Khi exclusion/gợi ý hoạt động sai?

    Kiểm tra lại cấu hình, phạm vi exclusion, và troubleshoot theo hướng dẫn của GitHub.

Ghi chúContent exclusions

Content exclusions ngăn Copilot truy cập nội dung nhạy cảm. Có thể cấu hình:

  • Repository-level — trong Settings của repo.
  • Organization-level — admin đặt rule cho toàn tổ chức (enterprise).
  • .copilotignore — file trong repo liệt kê đường dẫn cần loại trừ.

Ngoài ra có thể chỉnh editor settings để kiểm soát hành vi Copilot trong IDE.

Ghi chúSở hữu và giới hạn đầu ra

Bạn sở hữu code do mình viết (kể cả có Copilot trợ giúp). Tuy nhiên, gợi ý có thể trùng code công khai — khi đó cần xem xét license trước khi dùng. Copilot không đảm bảo code không vi phạm bản quyền.

Ghi chúBộ lọc code trùng public

Tính năng suggestions matching public code chặn những gợi ý trùng khớp code công khai. Khi bật, Copilot không hiển thị gợi ý khớp với public code (kèm tham chiếu nguồn). Cấu hình trong Settings của Copilot.

Ghi chúXử lý sự cố

  • Gợi ý vẫn xuất hiện từ file đã loại trừ → kiểm tra đường dẫn/pattern trong exclusion và .copilotignore.
  • Không nhận gợi ý → xác nhận đã bật inline suggestions và đăng nhập đúng tài khoản có seat.
  • Exclusion cấp org chưa có hiệu lực → kiểm tra policy admin và audit log các thay đổi.

Thực hànhÁp lên máy

  • 1. Tạo .copilotignoreThêm một file nhạy cảm vào .copilotignore, xác nhận Copilot không dùng nó.
  • 2. Bật public code filterVào Copilot Settings, bật "Suggestions matching public code".
  • 3. Kiểm tra exclusionĐặt exclusion cho một thư mục, hỏi Copilot nội dung trong đó.
  • 4. Đọc ownershipXem lại mục license của code Copilot gợi ý trước khi dùng vào dự án.

Một trangCheat sheet

Exclusions

  • Repo settings
  • Org (enterprise)
  • .copilotignore
  • Editor settings

Safeguards

  • Public code matching filter
  • Bạn sở hữu code mình viết
  • Chú ý license code trùng public

Troubleshoot

  • Kiểm tra pattern exclusion
  • Bật inline suggestions
  • Xem audit log thay đổi

Ngoài sáchMẹo thi bổ sung

  • Nhớ 3 nơi cấu hình exclusion: repo / org / .copilotignore.
  • Phân biệt "public code filter" (bản quyền) với "content exclusions" (bảo mật dữ liệu).
