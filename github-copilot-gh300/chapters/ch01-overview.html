Chapter 01 Exam Overview & GitHub Copilot

Exam overview and GitHub Copilot

Know the exam facts, the Copilot plans, and the four capability groups — this is the base for every plan-comparison and feature question on the exam.

The big picture

GH-300 tests how well you use Copilot to work faster, with higher quality and more security — not how well you write code by hand.

Recall check5 things you must remember

  1. Exam time, pass score, and validity of GH-300?

    100 minutes; pass at 700 or more; the credential is valid for 2 years.

  2. The four Copilot capability groups?

    Assistive, Agentic, Customizations, and External AI agents/models/tools.

  3. The main Copilot plans?

    Free, Student, Pro, Pro+, Max, Business, Enterprise (and Copilot access for enterprises).

  4. What are GitHub AI Credits?

    The unit that measures model usage; each paid plan has a monthly allowance.

  5. What are Copilot Free's limits?

    Auto model selection only, about 2,000 completions/month, and no Copilot Chat skills.

NotesWhat GitHub Copilot is

Copilot is an AI assistant that helps you write, understand, and ship software: it suggests code as you type, answers questions about your codebase, reviews changes, and works on tasks you assign it. Because it lives inside GitHub, it uses your code, history, issues, and pull requests as context.

Capabilities fall into four groups:

GroupDescription
AssistiveResponds while you work — code suggestions, answers, explanations. You review and apply each one.
AgenticYou describe a goal; Copilot works through multiple steps: researches the repo, proposes a plan, edits files, reviews PRs, prepares tasks for your review.
CustomizationsShape responses with instructions, reusable prompts, repo context, external tools, agent skills, and custom agents.
External AIThird-party agents, models, and tools (including MCP servers) work alongside Copilot, under the same security protections.
