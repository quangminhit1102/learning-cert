Dữ liệu và kiến trúc

Hiểu Copilot xử lý dữ liệu ra sao: từ khi bạn gõ đến khi gợi ý hiện ra, và các giới hạn của mô hình ngôn ngữ.

Bức tranh lớn

Copilot = ngữ cảnh của bạn (prompt + code + file mở) → xây prompt → gửi model → xử lý kết quả → hiển thị gợi ý. Chất lượng phụ thuộc cả ngữ cảnh lẫn giới hạn của LLM.

Tự kiểm tra5 điều bắt buộc nhớ

  1. Copilot dùng gì để xây prompt?

    Prompt của bạn + ngữ cảnh (code hiện tại, file đang mở, lịch sử chat).

  2. Vòng đời một gợi ý code?

    Gõ → thu thập ngữ cảnh → xây prompt → gửi model → phản hồi → post-processing → hiển thị.

  3. Proxy filtering và post-processing để làm gì?

    Áp content exclusions trước khi gửi; lọc kết quả (như trùng public code) trước khi hiển thị.

  4. Khác biệt dữ liệu giữa gói cá nhân và Business/Enterprise?

    Business/Enterprise không dùng dữ liệu để huấn luyện; gói cá nhân có thể dùng telemetry trừ khi tắt.

  5. Giới hạn chính của LLM?

    Giới hạn cửa sổ ngữ cảnh, không tất định, có thể sai hoặc tạo code không an toàn.

Ghi chúLuồng và cách dùng dữ liệu

Khi bạn dùng Copilot, dữ liệu gửi đi gồm prompt và ngữ cảnh xung quanh (đoạn code, file mở). Kết quả trả về được hiển thị cho bạn; việc dữ liệu có được giữ lại hay dùng để cải tiến sản phẩm tùy gói:

  • Copilot Business / Enterprise — prompt và suggestions không được dùng để huấn luyện mô hình.
  • Copilot Free / Pro (Individual) — GitHub có thể dùng telemetry/đoạn code để cải tiến sản phẩm, trừ khi bạn tắt tùy chọn.

Ghi chúXử lý input và xây prompt

Quá trình input processing: Copilot ghép prompt của bạn với ngữ cảnh được chọn (code hiện tại, file mở, lịch sử hội thoại) thành một prompt đầy đủ gửi tới model. Proxy filtering áp dụng các rule (như content exclusions) trước khi dữ liệu rời máy; post-processing lọc/điều chỉnh kết quả (ví dụ bỏ gợi ý trùng code public) trước khi hiển thị.

Ghi chúVòng đời gợi ý code

  1. Bạn gõ code hoặc yêu cầu.
  2. Copilot thu thập ngữ cảnh.
  3. Prompt được xây dựng.
  4. Model sinh phản hồi.
  5. Post-processing (lọc, chặn trùng public).
  6. Gợi ý hiển thị; bạn chấp nhận hoặc bỏ.

Ghi chúGiới hạn của LLM và Copilot

  • Cửa sổ ngữ cảnh giới hạn — model chỉ "nhìn" được một lượng dữ liệu nhất định; ngữ cảnh thừa có thể bị bỏ.
  • Không tất định — cùng prompt có thể cho kết quả khác nhau.
  • Có thể sai — sinh code lỗi logic hoặc API không tồn tại.
  • Không đảm bảo bảo mật — code sinh ra có thể chứa lỗ hổng.

Thực hànhÁp lên máy

  • 1. Quan sát ngữ cảnhMở 3 file liên quan, hỏi Copilot về một hàm; rồi đóng 2 file, hỏi lại và so sánh.
  • 2. Kiểm tra tính không tất địnhGửi cùng một prompt 2 lần, so sánh kết quả.
  • 3. Thử lọcĐặt một file vào content exclusion, xác nhận Copilot không gợi ý dựa trên nó.
  • 4. Ghi nhớ vòng đờiTự vẽ lại 6 bước vòng đời gợi ý ra giấy.

Một trangCheat sheet

Luồng dữ liệu

  • Prompt + ngữ cảnh → model
  • Proxy filtering trước khi gửi
  • Post-processing kết quả

Dữ liệu theo gói

  • Business/Enterprise: không huấn luyện
  • Free/Pro: có thể dùng telemetry (tắt được)

Giới hạn LLM

  • Context window
  • Không tất định
  • Có thể sai / không an toàn

  • Nhớ thứ tự vòng đời để trả lời câu "điều gì xảy ra trước/sau".
