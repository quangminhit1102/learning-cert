Chương 03 Copilot in the IDE

Copilot trong IDE

Copilot hoạt động trong VS Code, Visual Studio, JetBrains, Xcode và Eclipse. Biết cách kích hoạt và gọi đúng tính năng (inline, chat, agent mode) là phần lớn nhất của đề thi.

Bức tranh lớn

Ba cách tương tác chính trong IDE: gợi ý inline khi gõ, hội thoại trong Chat, và giao task cho agent mode tự thao tác nhiều bước.

Tự kiểm tra5 điều bắt buộc nhớ

  1. Copilot chạy trên những IDE nào?

    VS Code, Visual Studio, JetBrains, Xcode, Eclipse.

  2. Bốn cách kích hoạt Copilot trong IDE?

    Inline suggestions, Chat, CLI, và Agent mode.

  3. Inline suggestions gồm gì?

    Code completions theo thời gian thực và Next edit suggestions.

  4. Slash command dùng để làm gì?

    Gọi hành động nhanh trong Chat như /fix, /tests, /explain.

  5. Content exclusions để làm gì?

    Chặn Copilot truy cập các file/repo cụ thể bạn không muốn nó đọc.

Ghi chúBật Copilot trong IDE

Copilot được cung cấp qua extension/plugin của từng IDE. Sau khi cài, bạn đăng nhập bằng tài khoản GitHub có quyền dùng Copilot (gói cá nhân, hoặc seat do tổ chức cấp). Với thành viên tổ chức, admin phải gán seat trước.

Các thành phần thường cần bật: inline suggestions (completions), Copilot Chat, và (tùy gói) Agent mode. Chính sách của tổ chức có thể tắt/bật từng tính năng.

Ghi chúCác cách kích hoạt

CáchMô tả
Inline suggestionsGợi ý code ngay khi gõ; gồm code completions và Next edit suggestions (gợi ý sửa tiếp theo).
Copilot ChatHội thoại hỏi/đáp, giải thích, viết code theo yêu cầu; có inline chat ngay trong editor.
CLIDùng Copilot từ terminal (cài gh copilot).
Agent modeĐưa mục tiêu, agent tự tìm file, sửa code, chạy lệnh nhiều bước rồi báo cáo để bạn duyệt.

Ghi chúCopilot Chat trong IDE

Chat cho phép hỏi về code hiện tại, yêu cầu sửa/refactor, sinh test. Các công cụ nâng cao:

  • Slash commands — hành động nhanh: /fix, /tests, /explain, /doc.
  • Inline chat — gõ lệnh ngay trong file, không rời editor.
  • Gắn ngữ cảnh — dùng @ để gắn file, symbol; # để gắn issue/PR.
  • Copilot Chat skills — (không có ở gói Free) cho phép mở rộng khả năng chat.
Nhớ mở đúng file để Copilot dùng chúng làm ngữ cảnh; đóng các file không liên quan để gợi ý chuẩn hơn.

Thực hànhÁp lên máy

  • 1. Bật & đăng nhậpCài extension Copilot cho IDE của bạn, đăng nhập GitHub, xác nhận inline suggestions chạy.
  • 2. Gọi inlineGõ comment mô tả hàm rồi để Copilot sinh code; thử Next edit suggestions.
  • 3. Dùng chat + slashChọn một hàm, mở Chat, chạy /explain rồi /tests.
  • 4. Thử agent modeNêu một task nhỏ, xem agent tự tìm file và sửa, rồi review từng thay đổi.
