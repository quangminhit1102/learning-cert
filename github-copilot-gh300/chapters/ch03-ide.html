Chapter 03 Copilot in the IDE

Copilot in the IDE

Copilot works in VS Code, Visual Studio, JetBrains, Xcode, and Eclipse. Knowing how to enable it and trigger the right feature (inline, chat, agent mode) is the biggest part of the exam.

The big picture

Three main ways to interact in the IDE: inline suggestions as you type, conversation in Chat, and handing a goal to agent mode for multi-step work.

Recall check5 things you must remember

  1. Which IDEs support Copilot?

    VS Code, Visual Studio, JetBrains, Xcode, Eclipse.

  2. The four ways to trigger Copilot in the IDE?

    Inline suggestions, Chat, CLI, and Agent mode.

  3. What do inline suggestions include?

    Real-time code completions and Next edit suggestions.

  4. What are slash commands for?

    Quick actions in Chat such as /fix, /tests, /explain.

  5. What are content exclusions for?

    Blocking Copilot from reading specific files/repos you don't want it to see.

NotesEnabling Copilot in the IDE

Copilot is provided via an extension/plugin for each IDE. After installing, you sign in with a GitHub account that has Copilot access (an individual plan, or a seat assigned by your organization). For organization members, an admin must assign a seat first.

Components you typically enable: inline suggestions (completions), Copilot Chat, and (depending on the plan) Agent mode. Organization policies can enable/disable each feature.

NotesWays to trigger

WayDescription
Inline suggestionsCode suggested as you type; includes code completions and Next edit suggestions.
Copilot ChatConversational Q&A, explanations, code generation; inline chat inside the editor.
CLIUse Copilot from the terminal (install gh copilot).
Agent modeGive a goal; the agent finds files, edits code, and runs commands over multiple steps, then reports for your review.

NotesCopilot Chat in the IDE

Chat lets you ask about the current code, request edits/refactors, and generate tests. Advanced tools:

  • Slash commands — quick actions: /fix, /tests, /explain, /doc.
  • Inline chat — type commands right in the file, without leaving the editor.
  • Attach context — use @ to attach files/symbols; # for issues/PRs.
  • Copilot Chat skills — (not in Free) extend chat capabilities.
Keep the right files open so Copilot uses them as context; close irrelevant files for more accurate suggestions.

PracticeTry it

  • 1. Enable & sign inInstall the Copilot extension, sign in to GitHub, confirm inline suggestions run.
  • 2. Trigger inlineType a comment describing a function and let Copilot generate it; try Next edit suggestions.
  • 3. Chat + slashSelect a function, open Chat, run /explain then /tests.
  • 4. Try agent modeGive a small task, watch the agent find and edit files, then review each change.
