Chương 04 Copilot CLI & Advanced Features

Copilot CLI và tính năng nâng cao

Phần nặng nhất của đề: CLI, Agent Mode, Copilot Edits, MCP, Spaces, Spark, PR summary, code review và quản trị tổ chức.

Bức tranh lớn

Copilot mở rộng từ "gợi ý code" thành nền tảng: làm việc trong terminal, tự thao tác nhiều bước, kết nối tool ngoài, và được quản trị tập trung ở cấp tổ chức.

Tự kiểm tra5 điều bắt buộc nhớ

  1. Cài Copilot CLI thế nào?

    Cài GitHub CLI, gh auth login, rồi dùng lệnh gh copilot.

  2. Hai lệnh CLI cơ bản?

    gh copilot suggest (đề xuất lệnh) và gh copilot explain (giải thích lệnh).

  3. Agent Mode, Copilot Edits, MCP khác nhau ra sao?

    Agent Mode tự làm task nhiều bước; Edits chỉnh nhiều file nhanh; MCP kết nối công cụ ngoài.

  4. Spaces và Spark là gì?

    Spaces chia sẻ code làm ngữ cảnh với Copilot; Spark dựng ứng dụng từ mô tả tự nhiên.

  5. Admin tổ chức quản trị gì?

    Bật/tắt tính năng (gồm Code Review policy), xem audit log, quản subscription qua REST API.

Ghi chúGitHub Copilot CLI

Copilot CLI giúp dùng AI ngay trong terminal: gợi ý lệnh, giải thích lệnh, sinh script, thao tác file. Cài bằng GitHub CLI, sau đó đăng nhập bằng gh auth login.

LệnhMục đích
gh copilotVào chế độ tương tác/chat
gh copilot suggest <prompt>Đề xuất lệnh shell từ mô tả
gh copilot explain <command>Giải thích một lệnh shell

Trong phiên tương tác: gắn file bằng @path, gắn issue/PR bằng #number; có các lệnh như /chat, /undo, /rewind, và quản lý sessions.

Ghi chúAgent Mode, Copilot Edits và MCP

  • Agent Mode — Copilot tự đề xuất và thực hiện nhiều bước (tìm file, sửa, chạy lệnh); bạn quản lý Agent Sessions và ủy task cho Sub-Agents để tối ưu ngữ cảnh.
  • Copilot Edits — sửa nhanh nhiều file trong một lượt chỉnh sửa, xem trước diff rồi chấp nhận/từ chối.
  • MCP (Model Context Protocol) — kết nối Copilot với các server/công cụ ngoài để mở rộng khả năng.

Ghi chúCode review, Spaces, Spark và PR summary

  • Copilot code review — Copilot rà soát code/PR, gợi ý cải tiến; có thể cá nhân hóa chuẩn review bằng instructions files.
  • PR summaries — tự tóm tắt thay đổi trong pull request.
  • Spaces — không gian chia sẻ code để Copilot dùng làm ngữ cảnh.
  • Spark — sinh ứng dụng từ mô tả ngôn ngữ tự nhiên.
  • Prompt files — lưu prompt để tái sử dụng cho phản hồi nhất quán.

Ghi chúQuản trị cấp tổ chức

Admin có thể: quản lý policy toàn tổ chức, bật Copilot Code Review policies, bật/tắt tính năng trên các IDE và github.com, xem audit log events, và quản lý subscription (seat) bằng REST API.

Thực hànhÁp lên máy

  • 1. Cài CLICài gh CLI, gh auth login, chạy gh copilot suggest "list files by size".
  • 2. Giải thích lệnhDùng gh copilot explain "git rebase -i HEAD~3".
  • 3. Thử EditsMở VS Code, dùng Copilot Edits để đổi tên một hàm ở nhiều file.
  • 4. Đọc audit logNếu là admin org, xem audit log Copilot và policy hiện có.
