Chapter 04 Copilot CLI & Advanced Features

Copilot CLI and advanced features

The heaviest part of the exam: the CLI, Agent Mode, Copilot Edits, MCP, Spaces, Spark, PR summaries, code review, and organization-level administration.

The big picture

Copilot extends from code suggestions to a platform: working in the terminal, acting over multiple steps, connecting external tools, and being centrally managed at the org level.

Recall check5 things you must remember

  1. How do you install Copilot CLI?

    Install the GitHub CLI, run gh auth login, then use the gh copilot command.

  2. The two basic CLI commands?

    gh copilot suggest (propose commands) and gh copilot explain (explain a command).

  3. How do Agent Mode, Copilot Edits, and MCP differ?

    Agent Mode does multi-step tasks; Edits changes many files quickly; MCP connects external tools.

  4. What are Spaces and Spark?

    Spaces shares code as context; Spark builds apps from natural language.

  5. What do org admins manage?

    Feature toggles (including Code Review policies), audit logs, and subscriptions via REST API.

NotesGitHub Copilot CLI

The Copilot CLI brings AI into the terminal: suggest commands, explain commands, generate scripts, and manage files. Install the GitHub CLI, then sign in with gh auth login.

CommandPurpose
gh copilotEnter interactive/chat mode
gh copilot suggest <prompt>Propose a shell command from a description
gh copilot explain <command>Explain a shell command

In interactive sessions: attach files with @path, issues/PRs with #number; commands include /chat, /undo, /rewind, and session management.

NotesAgent Mode, Copilot Edits, and MCP

  • Agent Mode — Copilot proposes and performs multiple steps (find files, edit, run commands); manage Agent Sessions and delegate to Sub-Agents to optimize context.
  • Copilot Edits — edit multiple files in one pass, preview the diff, then accept or reject.
  • MCP (Model Context Protocol) — connect Copilot to external tool servers to extend its capabilities.

NotesCode review, Spaces, Spark, and PR summaries

  • Copilot code review — reviews code/PRs and suggests improvements; customizable via instructions files.
  • PR summaries — auto-summarize changes in a pull request.
  • Spaces — a space for sharing code as context for Copilot.
  • Spark — build an app from a natural-language description.
  • Prompt files — save reusable prompts for consistent responses.

NotesOrganization-level administration

Admins can manage organization-wide policy, enable Copilot Code Review policies, toggle features across IDEs and github.com, review audit log events, and manage subscriptions via the REST API.

PracticeTry it

  • 1. Install the CLIInstall the gh CLI, gh auth login, then run gh copilot suggest "list files by size".
  • 2. Explain a commandUse gh copilot explain "git rebase -i HEAD~3".
  • 3. Try EditsIn VS Code, use Copilot Edits to rename a function across files.
  • 4. Read the audit logIf you are an org admin, review the Copilot audit log and current policies.
